# Ollama

### Run large language models locally with one command

Ollama makes running powerful language models on your local machine as simple as a single terminal command. With a growing library of curated models and a clean REST API, it's the backbone of the local AI ecosystem.

<br>

---

## Features

| | |
|:---|:---|
| **One-Command Setup** | Pull and run any model with `ollama run llama3` — that's it |
| **REST API** | OpenAI-compatible API lets any app connect to your local models |
| **Model Library** | Llama 3, Mistral, Gemma, Phi, Qwen, and hundreds more ready to pull |
| **GPU & CPU** | Automatic GPU detection with seamless CPU fallback for any hardware |
